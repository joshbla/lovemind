# Wix Reference Archive

This directory records the public Wix site used as the fidelity source.

- `content/` contains route and copy inventories.
- `media/` contains the media manifest and downloaded source assets.
- `visual/` contains screenshots and interaction notes.

The archive may contain historical source material that is intentionally preserved even when `TODO.md` flags it for later review. Production pages must use curated local assets and must not depend on Wix URLs at runtime.
